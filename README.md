# Odyssey Fighter

A full-body fighting game for HackUTA 2026 (theme: Homer's Odyssey). Your webcam tracks your body; you block, dodge and strike monsters from the Odyssey, and the game teaches you each move mid-fight.

**Status: base project in progress.** The shared contracts, combat rules, pose signals, moves, styles and enemies are in. The 3D scene, screens and docs are landing next.

## Run it

```bash
make setup
```

```bash
make dev
```

`make check` runs lint, typecheck, tests and a build.
